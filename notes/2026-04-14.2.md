# Updating and Starting Classroom Sync Beta 0.1.1

1. Enter the following URL into the browser in your VM (this will download the updated extension in your Downloads folder)
    - https://hypertheory.nyc3.digitaloceanspaces.com/apps/classroom-sync-0.1.1.vsix
2. In Visual Studio Code (Not Visual Studio) 
    - Go to the extensions tab (the Lego brick looking icon on the left)
    - Scroll down to the Classroom Sync Extension, click the gear icon, and select uninstall
    - Close and Restart VS Code (or, Ctrl+Shift+P, Reload Window)
    - In the extensions tab, hit the ellipses (...) at the top and select "Install from Vsix"
    - Navigate to the Downloads folder and select the `classroom-sync-0.1.1.vsix` we downloaded in step 1.
3. Connect to Instructor Sync Server
    - Ctrl+Shift+P
    - Select `Classroom Sync: Connect to Instructor`
    - Enter the following: `172.18.0.10:3000?token=tacos` and hit enter.


## Using the Extension

> **Note**: This is the first run for this tool. It is beta. If we have problems, I have a plan "b", but won't know we should move to plan "b" unless you tell me you are having problems.

### During class — syncing a single file

If you fall behind and the instructor has moved a file forward:

1. Right-click the file in the Explorer.
2. Choose **Sync from Instructor**.
3. A dialog shows what will be overwritten. Confirm to pull the instructor's version.
4. To skip the confirmation in future syncs, choose **Always Allow** once. (You can reset this in settings: `classroomSync.alwaysAllowSync: false`.)

### During class — syncing a whole folder

If you missed several steps and want to catch up on a whole directory:

1. Right-click the folder in the Explorer.
2. Choose **Sync from Instructor**.
3. A dialog shows exactly what will be added, updated, and **deleted** (files in your folder that the instructor doesn't have). Review the list, then confirm.
4. The extension downloads the directory as a zip and extracts it atomically — either everything lands or nothing does.

### During class — browsing instructor files

If you want to pick specific files rather than sync a whole folder:

1. Run **Classroom Sync: Browse Instructor Files** from the command palette (or click the status bar item).
2. A searchable list of all files in the instructor's workspace appears, with last-modified times.
3. Select one or more files and confirm — they are written to the same relative paths in your workspace.

### Receiving pushed files from the instructor

When the instructor pushes a file to you, a notification pops up: *"Instructor pushed a file: incoming/lab1-pdf/lab1.pdf"*. Click **Show File** to open it, or find it in the Explorer under `incoming/`.
